# 微信公众号一镜到底长海报 V2

这版不是把多张独立海报直接纵向排列，而是六段内容母画面加五段无文字过场镜头：

1. 活动开场与到场信息；
2. 新生落地价值与社交；
3. 礼品与抽奖奖品；
4. 抽奖券玩法；
5. 完整现场路线与合作方类别；
6. 活动收口与报名提醒。

## 连续性规则

- JR Academy 官方 Logo 只在长图顶部覆盖一次。
- 中段不重复活动 Logo、届次、时间地点或页脚。
- 蓝色与珊瑚色路径从第一段贯穿到最后一段。
- 每两个内容段之间插入一个无文字过场镜头，让场景、人物、光线和路径先完成转变。
- 所有相邻画面只在 `120px` 无文字安全区做透明渐变融合，标题与正文不会在接缝处互相覆盖。
- 支持单位、主办方与报名提醒只在底部收口出现一次。
- 全图不放二维码，公众号正文活动链接负责报名承接。

运行 `bash build-continuous.sh` 可重建长图和六段总览图。
